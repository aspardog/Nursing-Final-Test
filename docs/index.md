# Quiz Enfermería

Simulador de examen final para estudiantes de enfermería con **354 tarjetas** de estudio en 4 temas principales.

[Iniciar Quiz](https://huggingface.co/spaces/santiagopardo03/test-enfermeria){: .btn .btn-primary }
[Guía de Uso](guia-app){: .btn }
[Importar a Anki](guia-anki){: .btn }

---

## Temas Disponibles

| Tema | Tarjetas | Contenido |
|------|----------|-----------|
| **Salud Mental** | 214 | Semiología psiquiátrica, funciones mentales, trastornos |
| **Urgencias** | 67 | Arritmias, IAM, ACV, emergencias metabólicas |
| **Cirugía** | 40 | Salas de cirugía, heridas, clasificación ASA, anestesia |
| **Mezclas** | 15 | Cálculos de diluciones e infusiones |

---

## Características

### App Web
- Quizzes configurables: 10, 20, 30 o 50 preguntas
- Modo mixto, solo opción múltiple, o solo preguntas abiertas
- Temporizador opcional por pregunta
- Feedback inmediato con explicación educativa
- Historial de sesiones

### Integración con Anki
- Importación automática via AnkiConnect
- Tarjetas tipo Basic y Cloze
- Sincronización con AnkiWeb para móvil
- Repetición espaciada para mejor retención

---

## Acceso Rápido

### Usar la App Web

1. Ir a [Quiz Enfermería en Hugging Face](https://huggingface.co/spaces/santiagopardo03/test-enfermeria)
2. Seleccionar cantidad de preguntas y modo
3. Elegir los temas a practicar
4. ¡Comenzar el quiz!

### Estudiar con Anki

1. Descargar [Anki](https://apps.ankiweb.net/)
2. Instalar [AnkiConnect](https://ankiweb.net/shared/info/2055492159) (código: `2055492159`)
3. Ejecutar el script de importación
4. Sincronizar con AnkiWeb

Ver la [guía completa de Anki](guia-anki) para instrucciones detalladas.
